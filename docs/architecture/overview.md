# Architecture Overview

## Principles

- **Code-centric:** Knowledge is linked to code, enabling navigation between code and its context.
- **Decoupled:** Knowledge lives outside the code repository and evolves independently.
- **Agent-native:** Agents can discover, read, write, and maintain knowledge.
- **Human-readable:** Markdown and wiki conventions make knowledge accessible to humans.

## Architecture

- **Workspace:** Provides a working environment for reading and editing knowledge.
- **Server:** Stores and synchronizes shared knowledge.
- **Interfaces:** CLI, editor integrations, and MCP provide access to Lore.
